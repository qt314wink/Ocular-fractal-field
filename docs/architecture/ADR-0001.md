# ADR-0001: Canonical Source and Environment Boundaries

**Status:** Accepted

## Decision

Framework-neutral modular TypeScript is the editable production authority. The standalone HTML distribution is generated output and must never become a second implementation authority.

The approved August 14 design and foundation documents define implementation authority. The PDF is supporting source evidence, not implementation authority. Its available bytes are the user-approved reconstruction recorded by the August 21 source-evidence reconstruction addendum. The missing original bytes remain unverified, and their former expected hash is provenance only.

Canonical domain packages are environment-free. Contracts, deterministic mathematics, simulation state, and replay logic cannot depend on the DOM, browser globals, Three.js, Web Audio, raw browser events, `Math.random`, or wall-clock authority. Environment adapters may consume immutable snapshots and ordered semantic events but cannot mutate canonical state.

## Consequences

- JSON Schema is structural authority and generated TypeScript is the code-facing contract.
- Canonical state advances only through fixed simulation ticks.
- Rendering, audio, input, haptics, and telemetry remain outward adapters.
- Generated artifacts and verification receipts record their source hashes and versions.
